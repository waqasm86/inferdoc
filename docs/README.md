# InferDoc documentation

InferDoc is an evidence-driven Python SDK and CLI for Nebius Token Factory. Start with the [offline replay](getting-started.md#first-offline-check) to inspect real, sanitized evidence without an API key. Live requests and Nemotron diagnosis use Token Factory credits.

## Start here

- [Getting started](getting-started.md): install, offline replay, first live call.
- [Configuration](configuration.md): settings, defaults, and secret handling.
- [Concepts](concepts.md): the measured baseline, bounded recommendation, and deterministic verdict.
